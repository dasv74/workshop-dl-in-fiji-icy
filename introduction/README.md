# Introduction


The introduction will be provided as a PDF before the workshop. The slide deck will cover:

- why established bioimage-analysis platforms still matter in the age of AI;
- the difference between a model, a prediction, and a complete analysis workflow;
- how Java-based tools connect to Python deep-learning models through [JDLL](https://github.com/bioimage-io/JDLL) and [Appose](https://github.com/apposed/appose);
- model choice, input/output dimensions, preprocessing, and reproducibility;
- opportunities, limitations, ethical questions, and risks of AI in bioimage analysis.
